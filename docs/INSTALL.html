X MEDIA DOWNLOADER / QUICK START

解压之后，就能开始使用。

适用于 Chrome 与 Microsoft Edge。无需安装 Node.js，无需编译源码。

v7.7.0 · 已解压扩展
1

把压缩包完整解压

右键 ZIP 文件，选择「全部解压」或「解压到文件夹」。把扩展放在固定位置，之后请保留这个文件夹。

📁 X-Media-Downloader

打开后应能看到 manifest.json、content.js、background.js 等文件。

2

打开浏览器的扩展管理页

复制对应地址到浏览器地址栏，按 Enter 打开，然后开启「开发者模式」。

Google Chromechrome://extensions
Microsoft Edgeedge://extensions
3

加载刚刚解压的文件夹

点击「加载已解压的扩展程序」，选择 X-Media-Downloader 文件夹并确认。

请选能直接看到 manifest.json 的这一层，不要选择 ZIP 文件，也不要选择包含安装说明的外层目录。

4

刷新 X 页面，开始下载

打开或刷新 x.com。点击浏览器工具栏中的扩展图标展开面板，或把鼠标放到图片、视频上使用下载按钮。

批量保存：进入博主媒体页 → 点击「扫描」或「加载」→ 点击「下载所选」。已下载的媒体会自动跳过。

以后怎么更新？

下载新版本并解压，用新文件替换原来 X-Media-Downloader 文件夹里的内容。保持原文件夹路径不变，到扩展管理页点击「重新加载」，最后刷新 X 页面。

如果浏览器提示找不到清单文件，请先确认已完整解压，再检查所选文件夹里是否有 manifest.json。
